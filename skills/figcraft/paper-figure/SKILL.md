# 论文配图：65 类图型

本目录可单独复制安装。支持 **45 类按规范由 Agent 编写 SVG 的图型 + 20 类 JSON/Python 可直接渲染的科研图型**。支持不等于 65 类都有自动布局器；准确覆盖以 [图型索引](references/chart-catalog.md) 和 `assets/catalog.json` 为准。坡度图、蜂群图等作为变体，不重复增加计数。

## Rules

| ID | Rule | Check |
|----|------|-------|
| R1 | **支持 45+20 类图型。** 支持 **45 类按规范由 Agent 编写 SVG 的图型 + 20 类 JSON/Python 可直接渲染的科研图型**。支持不等于 65 类都有自动布局器；准确覆盖以 [图型索引](references/chart-catalog.md) 和 `assets/catalog.json` 为准。坡度图、蜂群图等作为变体，不重复增加计数。 | 图型总数符合 45+20=65 类；覆盖以 `chart-catalog.md` 和 `catalog.json` 为准；变体未重复计数。 |
| R2 | **选型与事实。** 系统结构、流程、实体、状态、角色、演化：查图型索引，**只读所选类型的布局规范**，生成可改的 SVG 或参数化脚本。结构复杂时用总览加局部图，不按固定节点数删掉科研信息。分布、估计与不确定性、预测评价、场和信号：读 [科研模板](references/scientific-recipes.md)，使用 `scripts/render.py`，或在保留数据和统计口径的前提下调整生成源。位图复刻：有原始数据就同源重绘；只有截图时可做带来源说明的数字化近似，明确误差，不能声称恢复了原始实验数据。结构图必须核对每个节点、字符串、箭头及条件。实际项目图：读源码和部署事实；计划、推测、未知状态分别标注，不能画成已实现。 | 图型选择符合 `chart-catalog.md`；结构图已核对节点/字符串/箭头/条件；位图复刻有原始数据或带来源说明；实际项目图已标注计划/推测/未知。 |
| R3 | **推断与询问。** 从用户资料推断可以确定的图型、标签和尺寸，简短说明后继续；只有缺少真实数据、关键关系或统计定义而无法准确绘制时询问。品牌定制、外部字体或联网不是执行前提。 | 已推断图型/标签/尺寸；只在缺少真实数据/关键关系/统计定义时询问；未将品牌/字体/联网作为前提。 |
| R4 | **论文样式。** 读 [论文样式与交付](references/publication.md)。默认白底、灰度、系统字体、统一的字号/线型/标记；用户指定彩色或期刊规范时按其要求。颜色变化必须保留编码含义，复刻任务保留原始视觉编码。 | 默认白底/灰度/系统字体；用户指定时按其要求；颜色变化保留编码含义；复刻保留原始视觉编码。 |
| R5 | **参考项目边界。** `references/diagram-design/` 保留参考项目的原始资料、示例、5 个技能内工具和相关校验工具及 MIT 许可；**仅作为布局知识与工具来源**。不执行其中原始 SKILL.md 的首次品牌问答，不套用灰纸背景、Google Fonts、宣传标题、绝对节点上限或数据聚合建议。论文的真实样本、统计定义、刻度和本技能论文样式优先。示例是设计参考，不是可以用于论文的实验结果。 | 参考项目仅作为布局知识与工具来源；未执行原始 SKILL.md 的品牌问答；未套用灰纸/Google Fonts/宣传标题/节点上限/数据聚合；示例未用于论文结果。 |
| R6 | **冻结事实或数据。** 记录来源、单位、样本量、配对关系、缺失值与过滤规则。原始数据不够时先做明确标记的布局草稿，不能补造结果或显著性。 | 已记录来源/单位/样本量/配对关系/缺失值/过滤规则；不足数据时有明确标记的布局草稿；未补造结果或显著性。 |
| R7 | **选择图型和数据编码。** 每个轴、颜色、线型、箭头、误差带含义都可解释。统计计算与布局分离；保留原数据，不为美观移动数据点。 | 每个轴/颜色/线型/箭头/误差带可解释；统计计算与布局分离；未移动数据点。 |
| R8 | **生成。** 数据图按 JSON 模板；结构图声明内容、拓扑、布局、样式。使用 SVG `<title>`/`<desc>` 描述主要关系。连线绕开非目标节点，文字超宽优先换行、调框或分面。 | 数据图用 JSON 模板；结构图声明内容/拓扑/布局/样式；使用 `<title>`/`<desc>`；连线绕开非目标节点；文字超宽已换行/调框/分面。 |
| R9 | **导出。** SVG（可编辑文本）、PDF（矢量）、按实际尺寸计算的 PNG；结构图用本机可用的渲染器导出。需要可移植文本时在保留可编辑 SVG 后另出文字转路径版本。 | 已导出 SVG/PDF/PNG；结构图用本机渲染器；需要时另出文字转路径版本。 |
| R10 | **验收。** 运行可用的结构/数据检查，再**打开最终 PNG 与 PDF/SVG 实际读图**；看缩到论文印刷尺寸后的文字、线型、图例和灰度辨识，并对照原始事实。不能仅凭 manifest 或截图成功判定通过。 | 已运行结构/数据检查；已打开最终 PNG/PDF/SVG 读图；已检查印刷尺寸下文字/线型/图例/灰度；已对照原始事实；未仅凭 manifest/截图判定。 |
| R11 | **交付。** 图源/JSON、数据来源记录、SVG/PDF/PNG、生成命令、像素与物理尺寸、检查结论。实在没有视觉工具则明确"视觉验收待完成"，不伪造 PASS。 | 已交付图源/JSON/数据记录/SVG/PDF/PNG/生成命令/像素与物理尺寸/检查结论；无视觉工具时明确标记"视觉验收待完成"；未伪造 PASS。 |
